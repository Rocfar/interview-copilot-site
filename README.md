# Interview Copilot

用于模拟面试练习的轻量 PWA。用户可通过文字或浏览器语音识别输入面试问题，由 AI 以流式方式生成候选人示范回答。

## 已实现功能

- 文字输入与浏览器语音识别
- 快速、标准、深入三档回答长度
- 兼容 OpenAI 格式的流式接口
- 停止生成、复制回答和最近四轮上下文
- API Base、API Key、模型名保存在当前浏览器
- PWA 安装、静态资源离线缓存和移动端适配

## 项目结构

```text
.
├─ index.html
├─ manifest.webmanifest
└─ sw.js
```

## 使用

打开网页后，在“接口设置”中填写支持浏览器跨域访问的兼容接口：

- `API Base`：例如 `https://api.example.com/v1`
- `API Key`
- `模型名`：模型或接入点 ID

接口设置只存储在当前浏览器的 `localStorage`，不会提交到 GitHub。请勿在公共设备保存密钥。

## 部署

项目为纯静态网页，可直接部署到 GitHub Pages，无需单独的云端服务。

## 使用边界

本项目仅用于模拟面试和日常练习，不应用于正式面试中的实时作弊。
