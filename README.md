# Interview Copilot

用于模拟面试练习的轻量 PWA。用户可通过文字或浏览器语音识别输入面试问题，由豆包以流式方式生成候选人示范回答。

## 已实现功能

- 文字输入与浏览器语音识别
- 快速、标准、深入三档回答长度
- 内置火山方舟豆包对话 API 地址
- 停止生成、复制回答和最近四轮上下文
- API Key 和模型 ID 保存在当前设备的浏览器中，下次打开自动读取
- PWA 安装、静态资源离线缓存和移动端适配

.

## 使用

打开网页后，在“豆包 API 接入”中填写：

- 火山方舟 `API Key`
- 豆包模型 ID 或推理接入点 ID（`ep-...`）

请求固定发送到火山方舟官方接口 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`。API Key 和模型 ID 保存在当前浏览器的 `localStorage`，不会提交到 GitHub。首次保存后，在同一设备、同一浏览器中再次打开会自动读取；换设备或浏览器仍需重新填写。

不要在公共或共享设备保存 API Key，可随时点击页面中的“清除保存配置”。纯前端直连要求火山方舟允许浏览器跨域请求。

## 部署

项目为纯静态网页，可直接部署到 GitHub Pages，无需单独的云端服务。

## 使用边界

本项目仅用于模拟面试和日常练习，不应用于正式面试中的实时作弊。
