# Interview Copilot

用于模拟面试练习的轻量 PWA。用户可通过文字或浏览器语音识别输入面试问题，由豆包以流式方式生成候选人示范回答。

## 已实现功能

- 文字输入与浏览器语音识别
- 快速、标准、深入三档回答长度
- 内置火山方舟豆包对话 API 地址
- 停止生成、复制回答和最近四轮上下文
- API Key 仅保留在当前标签页，模型 ID 保存在当前浏览器
- PWA 安装、静态资源离线缓存和移动端适配

## 项目结构

```text
.
├─ index.html
├─ manifest.webmanifest
└─ sw.js
```

## 使用

打开网页后，在“豆包 API 接入”中填写：

- 火山方舟 `API Key`
- 豆包模型 ID 或推理接入点 ID（`ep-...`）

请求固定发送到火山方舟官方接口 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`。API Key 只保存在当前标签页的 `sessionStorage`，关闭标签页后清除，不会提交到 GitHub。

纯前端直连要求火山方舟允许浏览器跨域请求；如果浏览器报告 CORS 错误，则必须使用非腾讯云的服务端代理才能安全调用。

## 部署

项目为纯静态网页，可直接部署到 GitHub Pages，无需单独的云端服务。

## 使用边界

本项目仅用于模拟面试和日常练习，不应用于正式面试中的实时作弊。
