# Interview Copilot

用于模拟面试练习的轻量 PWA。用户可通过文字或浏览器语音识别输入面试问题，由豆包以流式方式生成候选人示范回答。

## 已实现功能

- 文字输入与浏览器语音识别
- 快速、标准、深入三档回答长度
- 内置火山方舟豆包对话 API 地址
- PDF、DOCX、TXT 简历本地解析、编辑、保存和清除
- PDF、DOCX、TXT 岗位 JD 本地解析，也支持直接粘贴
- 可随时选择启用或停用 JD 作为回答依据
- 结合简历明确事实与岗位要求生成回答，避免补造经历或混淆团队成果
- 停止生成、复制回答和最近四轮上下文
- API Key、模型 ID 和简历文字保存在当前设备的浏览器中
- PWA 安装、静态资源离线缓存和移动端适配

## 使用

打开网页后，在“豆包 API 接入”中填写：

- 火山方舟 `API Key`
- 豆包模型 ID 或推理接入点 ID（`ep-...`）

请求固定发送到火山方舟官方接口 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`。API Key 和模型 ID 保存在当前浏览器的 `localStorage`，不会提交到 GitHub。首次保存后，在同一设备、同一浏览器中再次打开会自动读取；换设备或浏览器仍需重新填写。

不要在公共或共享设备保存 API Key，可随时点击页面中的“清除保存配置”。纯前端直连要求火山方舟允许浏览器跨域请求。

在“简历背景”中可以导入 10MB 以内、30 页以内的 PDF，或 DOCX、TXT 文件。解析完全在浏览器本地进行，原文件不会上传；解析文字会保存在当前浏览器，并在每次提问时发送给豆包。扫描版 PDF 需要先完成 OCR。

在“岗位 JD”中可以导入相同格式的文件，也可以直接粘贴岗位职责和任职要求。通过“回答时参考 JD”开关可决定本次回答是否使用 JD；JD 只用于调整回答侧重点，不会被当作候选人的个人经历。

## 部署

项目为纯静态网页，可直接部署到 GitHub Pages，无需单独的云端服务。

## 使用边界

本项目仅用于模拟面试和日常练习，不应用于正式面试中的实时作弊。
